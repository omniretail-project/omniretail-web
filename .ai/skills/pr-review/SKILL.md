# OmniRetail PR Review

## Branch Destino

`development`.

## Checklist

- Scope correcto.
- Ownership.
- Duplicacion de Entities.
- Acceso directo a localStorage.
- Uso incorrecto de `core/`.
- Cambios de contratos no coordinados.
- Shared duplicado.
- Logica de negocio dentro de Shared.
- Estados hardcodeados en lugar de enums/config.
- Colores hardcodeados cuando existen tokens.
- Repository correcto.
- Eventos.
- Seguridad simulada razonable.
- Datos sensibles.
- `any` / `ts-ignore`.
- `npm run lint`.
- `npm run build`.
- Rutas Next.
- Dependencia entre modulos.
- Tamano del PR.

## Salida

- Critical
- Important
- Minor
- Approved / Changes requested

No modificar el codigo durante review salvo instruccion explicita.
